Variables utilisées : `DQ_APK`, `DQ_SAVES`, `DQ_CACHE_CARTES=/tmp/cache44`, `PYGLET_AUDIO=silent`. Le dump IL2CPP (lecture du C# du jeu) se régénère avec `tools/dump_il2cpp.bat` / `generate_ui.bat` (côté Windows) ; il sert à lire les classes Unity, pas à être publié.
3. Python : `pip install --break-system-packages numpy pillow unicorn pyglet UnityPy capstone soundfile`. Plus besoin de xvfb : `PYGLET_HEADLESS=1` (EGL).
4. **Tests** : toujours depuis la racine du dépôt, en script : `PYGLET_HEADLESS=1 python3 tests/test_X.py` (jamais `-m unittest`, certains tests importent leurs voisins via le dossier du script). `tools/session_flow/run_tests.sh` lance toute la suite (une ligne par fichier, `FIN` à la fin). Certains tests acceptent `--apk --saves`, d'autres non (`test_casino_bestiary`, `test_battle_transition`). Importer pyglet sans écran exige `pyglet.options['shadow_window']=False`.
5. **Lancer la visionneuse en capture** : `PYGLET_HEADLESS=1 PYGLET_AUDIO=silent python3 -m dq4_pc --apk ... --saves-lecture ... --saves-ecriture /tmp/sv_X --reglages /tmp/rg_X.json --slot 1 --cache /tmp/uicache4 --msaa 0 --largeur 1280 --hauteur 720 --sans-preparation --sans-son --shot /tmp/m_X.png --images 100000 --touches-test "" --shots-boucle "150,330"` (captures séparées par des **virgules**). `--slot 1` = journal 1, `0` = logos + titre + menu de départ.
