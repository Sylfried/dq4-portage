- Title scene = TownPart map `ev01`, camera `_town_camera` + `s_yOffset`; constants `TITRE_HAUT = 0.3` (raises logo/island/sky; credits recentered by `_decalage_credits`) and `TITRE_DRAGON_HAUT = 0.0` (dragon not raised).
