# Dragon Quest IV : portage PC natif (sans Unity)

Portage natif sur PC de **Dragon Quest IV (Android)**, à partir de la version déjà patchée en français. Premier objectif : un affichage **16/9** propre, avec les fenêtres, les menus, la souris (= tactile du mobile), la musique et les bruitages d'origine.

## Principe (« voie A »)
Le jeu Android est un moteur C++ autonome (`libdq4core.so`, ARM64) piloté par une couche Unity. On garde le moteur d'origine et on réécrit la couche Unity en Python. Le fichier `libdq4core.so` n'est **jamais modifié** (il est lu dans l'APK et exécuté en mémoire), mais la visionneuse y pose en mémoire quelques correctifs ciblés et des crochets (lieux de la carte du monde en 16/9, bouton « Paramètres », vitesse du texte, vitesse des combats, marche accélérée, modification PV / PM…) : la liste complète, une ligne par site, est dans la section « Écritures et crochets en mémoire du moteur » de [`docs/notes-technique-portage-dq4.md`](docs/notes-technique-portage-dq4.md). Aucun ne touche un drapeau de scénario, l'or, l'inventaire ni la position du héros ; trois changent pourtant une valeur de la partie : la vitesse des messages de combat (une option du jeu, enregistrée dans ses sauvegardes), le compteur de rencontres aléatoires quand la marche est accélérée, et les PV / PM au niveau supérieur (menu « Modifications », désactivée par défaut) :

- `dq4_pc/emu_core.py` : chargeur ELF AArch64 + [Unicorn](https://www.unicorn-engine.org/) qui exécute `libdq4core.so` ;
- `dq4_pc/moteur.py` / `pktlog.py` : pilotage du moteur (`GameUpdate`…), décodage des paquets moteur → Unity, file de messages des menus ;
- `dq4_pc/fld.py` / `donnees.py` : lecture des cartes et sprites dans les données Unity (UnityPy) ;
- `dq4_pc/fenetre.py` : fenêtre pyglet/OpenGL (décor 3D, sprites, combat, carte du monde, caméra 16/9, souris et clavier) ;
- `dq4_pc/ui_menu.py` : fenêtres et menus d'origine, dont la mise en page est lue dans le code C# du jeu (`outils/ui_il2cpp/`) ;
- `dq4_pc/son.py` : musiques et bruitages d'origine (conteneur AKB) ;
- `dq4_pc/hd.py` : agrandissement des sprites (EPX x8) et mode pixel perfect ;
- `dq4_pc/postfx.py` : rendu hors écran (anticrénelage MSAA, suréchantillonnage, netteté, luminosité) ; `dq4_pc/decors_plats.py` : fin du scintillement des décors plats superposés ;
- `dq4_pc/pause.py` / `reglages.py` : menu Pause (Échap) et réglages du joueur (`reglages.json`) ; `dq4_pc/etats.py` : états instantanés ; `dq4_pc/historique.py`, `historique_combat.py`, `ui_historique.py` : historique des dialogues et des combats ; `dq4_pc/hud_mobile.py` : boutons et croix tactiles à l'écran ;
- `dq4_pc/avant_partie.py`, `saisie_nom.py`, `ecran_sauvegardes.py` / `sauvegardes.py` : avant la partie (logos, titre, menu de départ, nom du héros, export / import des sauvegardes) ;
- `outils/` : les tests (`test_*.py`, 47 fichiers), la lecture de la mise en page des menus (`ui_il2cpp/`, `dump_il2cpp.bat`, `generer_ui.bat`), les scripts de la session de travail (`flux_session/`) et les scripts de recherche non maintenus (`recherche/`).

## ⚠️ Aucun contenu Square Enix ici
Ce dépôt ne contient **que du code et des notes**. Le programme lit *tes* fichiers (APK patchés, sauvegardes) sur *ton* PC ; rien n'est copié ni distribué. Les APK, `.so`, données Unity, sauvegardes, caches et captures du jeu sont exclus par `.gitignore` : ne jamais les forcer (`git add -f`).

## Lancer (Windows)
Il faut les 3 APK français et une sauvegarde, dans le dossier `jeux\DQ4` **de ce dépôt** (le projet ne dépend d'aucun autre dossier ; variable `DQ4_JEUX` pour en indiquer un autre). Disposition simple, dans ce dépôt :

```
dq4-portage\
  jeux\DQ4\patched_apks\   (base.apk, split_config.arm64_v8a.apk, split_UnityDataAssetPack.apk)
  jeux\DQ4\saves\<horodatage>\data1.dat
  dq4_pc\lancer_dq4.bat      <- double-clic
```
`lancer_dq4.bat` crée un environnement Python local (3.13 > 3.12 > 3.11 > 3.14 > 3.10), installe `numpy pillow unicorn pyglet UnityPy capstone soundfile` une fois, puis ouvre la fenêtre. Les nouvelles sauvegardes vont dans `dq4_pc\sauvegardes` (les tiennes ne sont jamais modifiées). Au premier lancement après une mise à jour, le lanceur refait la mise en page des menus d'origine (quelques minutes, une seule fois ; il lui faut pour cela le dump du code du jeu `dq4_pc\cache\il2cpp\dump.cs`, produit sur ton PC par `outils\dump_il2cpp.bat` : sans lui, le jeu s'ouvre avec des menus simples) et le jeu prépare de nouveau le cache des cartes en arrière-plan (environ une minute et demie, le jeu reste jouable) : les animations de décor (eau, lampes, scintillements) viennent de ce cache.

**Avant la partie** : le jeu démarre comme sur mobile : logos **SQUARE ENIX** et **ArtePiazza** (un clic ou une touche saute l'attente), écran-titre (« Touchez l'écran » : clic, Entrée ou Espace, deux fois), puis le **menu de départ** : *Continuer votre aventure* (un des trois journaux), *Reprendre une aventure interrompue*, *Créer un nouveau journal* (emplacement, **nom** au clavier de l'ordinateur ou à l'écran, sexe, puis le prologue : bandeau « Prologue » sur fond noir, coups d'épée, puis la salle), *Supprimer un journal* (avec confirmation), *Sauvegarde automatique*, *Licence* (en tête, une section en anglais sur le portage et les composants utilisés ; le texte d'origine suit, inchangé ; défilement à la molette ou à la barre) et **Sauvegardes** (exporter tes journaux et états instantanés dans un .zip, importer un .zip ou des fichiers `data1.dat`… copiés depuis un téléphone ; les fichiers remplacés sont d'abord copiés dans `avant_import_…`). Souris, flèches + Entrée / Espace ; Échap ou Retour arrière = annuler. `--slot 1` à `5` charge directement un journal (sans logos ni titre) ; `--sans-logos` saute les logos. Le bouton « Sauv. cloud » du jeu mobile (Google Play Games) n'existe pas sur PC : le bouton *Sauvegardes* le remplace.

Touches par défaut (modifiables dans le menu Paramètres (Échap) > Commandes ; **F1** = infos à l'écran, réattribuable aussi) : **Z Q S D** (se déplacer, par rapport à la caméra), **Flèches ← →** (tourner la caméra des villes, donjons et tours, comme sur mobile), **Flèches ↑ ↓** (relever / abaisser l'angle de la caméra ; appuyer sur les deux flèches d'une même direction recentre la caméra en douceur, par le plus court chemin : 1° plutôt que 359° ; sur la carte du monde la vue reste de dessus, sans rotation ni inclinaison), **Pavé + / Pavé -** ou **E / W** (rapprocher / éloigner la caméra, par pas de 5 % entre 50 et 200 %, comme le curseur « Distance caméra » et la molette ; maintenue, la touche répète), **Espace** (bouton d'action : parler, examiner, ouvrir un coffre, casser un tonneau ou une jarre, valider ; **un clic sur la bulle** au-dessus d'un personnage ou d'un coffre, ou **un toucher du rond central de la croix** à l'écran, donnent la même touche d'action), **Alt seul, au relâchement** (discussion de groupe), **Entrée ou Tab** (touche « Menu » : ouvre le menu de commandes hors combat, valide dans un menu ; Tab est la seconde touche par défaut, retirée ou changée dans Commandes ; un `reglages.json` d'avant, qui avait encore Entrée seule, reçoit Tab une fois), **Retour arrière** (annuler / retour), **M** (carte ; en ville, M ouvre le plan, un 2e appui la liste des boutiques (← / → : boutique suivante ou précédente), un 3e ferme), **Maj** (touche d'accélérateur, tenue : accélère la marche et la caméra, multiplicateur réglable de 1 à 2 dans Commandes, 1,5 par défaut, sans effet en combat (les combats ont leur propre vitesse) ; l'accélération de la marche accélère toute l'horloge du jeu : le héros, mais aussi les PNJ et les animations ; l'équipe garde la même distance, en ville comme sur la carte du monde, et le taux de rencontre reste le même pour une même distance parcourue), **Maj + touche de la caméra** (accélère aussi la caméra, avec la même touche d'accélérateur), **Ctrl + touche de la caméra** (« Touche spéciale », réattribuable : remet la caméra à zéro dans tous les sens ; les lieux dont le jeu verrouille la caméra ne tournent pas), **A / Page haut** et **R / Page bas** (page précédente / suivante des menus). **Boutons de la version mobile à l'écran** (Carte, Mode de la carte (seulement carte ouverte : passe de la vue détaillée à la carte du monde entière, avec ses zones non explorées grisées et ses lieux rouges clignotants), Commandes, Discussion de groupe, sur des plaques comme dans la version mobile, **à gauche de l'écran par défaut** ; clic de souris). **Croix à l'écran** (la manette tactile du jeu : anneau, huit pastilles de direction, boule ; **en bas à droite par défaut**, presque transparente au repos) : on appuie dessus avec la souris et on glisse, la direction est l'un des huit secteurs de 45° et suit la caméra comme les touches ; sa taille se règle dans l'éditeur d'interface (« Taille de la croix ») ; elle se masque, se redimensionne et se déplace dans l'éditeur d'interface (« Afficher la croix », « Taille de la croix »). **Éditeur d'interface** (menu Pause > Affichage > Interface) : afficher / masquer l'interface à l'écran, liste déroulante, par groupes aux intertitres discrets (gris doré, l'or marque la valeur courante), de tout ce qu'on peut modifier (boutons et croix de l'écran, dialogues et toutes les fenêtres du jeu : menus, magasins, combat... ; le bouton de vitesse de combat a sa propre entrée « Combat : bouton de vitesse » : affichage, taille, position), taille et position de chaque élément avec aperçu (↺ à droite de chaque curseur ; « Rétablir cette interface » remet les tailles et les positions de l'interface choisie, « Rétablir toutes les interfaces » toutes), placement des boutons et des fenêtres par glisser-déposer, avec grille (affichage et aimantation au choix) pour toutes les interfaces ; la fenêtre de réglage s'ouvre toujours en haut à droite et se replie / se déplie (Tab ou clic sur sa barre de titre) pour libérer l'écran ; l'aperçu des dialogues montre un texte d'essai au hasard (trois lignes au plus) et celui des boîtes de combat reste à trois lignes. **Nom de l'interlocuteur** : la boîte de dialogue du terrain montre le nom dans un onglet souligné collé en haut à gauche, comme sur mobile, seulement quand le jeu l'envoie (jamais en combat ; l'aperçu de l'éditeur n'a pas l'onglet). **Chiffres 1 à 9 et 0 = enregistrer l'état instantané n° 1 à 10, Ctrl + chiffre = le charger, Ctrl + Maj = annuler le dernier chargement.** **Échap = menu Pause** (dans l'ordre : Reprendre ; **Historique** (voir plus bas) ; **États** (un seul menu : créer, charger ou supprimer un état instantané, avec miniature ; la suppression demande confirmation dans une fenêtre Oui / Non), **Affichage** (dans l'ordre : Plein écran oui / non, écran du plein écran (Automatique : celui où se trouve la fenêtre, ou un moniteur choisi), résolution de 720p à 4K, netteté, shader, effet de vignetage, anticrénelage MSAA x2 / x4 / x8, suréchantillonnage x1,5 / x2, luminosité, distance de la caméra de 50 à 200 % (la caméra reste toujours centrée sur le héros, même près du bord de la carte, sauf quand le jeu la prend en main), éditeur d'interface en dernier ; le mode choisi s'applique dès l'ouverture de la fenêtre ; **F11** ou **Alt + Entrée** : plein écran ↔ fenêtre, depuis n'importe quel écran) ; **Son** (une ligne par type : général, musique, jingles, bruitages, interface ; barre de volume, bouton muet, bouton par défaut) ; **Commandes** (sept sections : Déplacement, Caméra au clavier, Caméra à la souris, Vitesses, Défilement du texte, Actions du jeu, Autres) : touches de déplacement et de caméra, section Caméra à la souris (inversion gauche / droite et haut / bas en option, rappel des gestes), section Vitesses (vitesse de marche, vitesse de caméra et vitesse de transition en x1 / x2 / x3 / x4, touche d'accélérateur et multiplicateur de l'accélérateur de 1 à 2, 1,5 par défaut, touche **V** « Changer la vitesse en combat » ; puis, juste dessous, la section **Défilement du texte** : **Vitesse du texte** (de Très lent à Instantané, Normal = comme le jeu) et **Vitesse de combat** : Manuel (messages passés à la main) / Normal / Rapide / Très rapide, x1 / x2 / x3, qui accélère animations (ennemis compris) et messages mais ni la musique ni les bruitages, aussi réglable en combat par la touche **V** et le bouton à l'écran ; chaque réglage a un bouton ↺ qui remet sa valeur d'origine), touches des actions du jeu, avec une barre de défilement quand la liste ne tient pas ; chaque touche se remet à celle d'origine avec le bouton ↺ de sa ligne (ou Début) et chaque case se vide avec sa croix rouge (ou Suppr) ; l'aide des curseurs et des touches s'affiche en infobulle au survol ; **Modifications** (juste sous Commandes ; ex-page « Jeu », qui accueillera d'autres modificateurs) : une option, désactivée par défaut, qui rend tous les PV et PM à chaque montée de niveau ; **Revenir à l'écran titre** (en ville et sur la carte du monde, grisé ailleurs) : la boîte d'origine du jeu, avec son texte et ses boutons Oui / Non (Non rend la main sans rien changer ; Oui lance le fondu au noir du jeu puis le titre), c'est le seul chemin de retour au titre ; au menu de départ, quitter l'application pose la même question). Les fenêtres du menu sont noires, avec le curseur doré du jeu ; le bouton retour du jeu (en bas à droite de la fenêtre) remonte d'un cran, comme Échap, Retour arrière ou le clic droit. Les curseurs se règlent en glissant, aux flèches ou en cliquant sur la valeur pour la taper ; le bouton ↺ à droite du curseur (ou Suppr) remet la valeur par défaut. La molette de la souris règle aussi la distance de la caméra ; **clic molette maintenu + mouvement** = faire tourner la caméra dans toutes les directions, **clic molette simple** = remettre la direction par défaut, **Ctrl + clic molette** = remettre le zoom à 100 %. **H** (ou menu Pause > Historique) ouvre l'historique des dialogues hors combat ; un 2e appui ouvre celui des combats (l'issue : victoire, fuite ou défaite ; chaque espèce de monstres, avec ceux qui sont vaincus, enfuis, disparus ou restés ; l'or, l'expérience et les objets gagnés), un 3e ferme. Chaque dialogue est dessiné dans une boîte de la taille d'une boîte de dialogue du jeu (cadre et onglet du jeu, trois lignes, même police), que le texte tienne sur une, deux ou trois lignes ; un dialogue plus long continue dans une boîte suivante (« 2/2 »). Une boîte de combat grandit en hauteur pour tout contenir (jusqu'à 12 lignes, puis une boîte suivante). Le nom de l'interlocuteur est dans son onglet souligné, comme en jeu, seulement quand le jeu l'affichait. Tout disparaît à la fermeture de la visionneuse, sauf les éléments marqués d'une étoile (Entrée ou clic) : ils sont gardés dans `dq4_pc\historique_favoris.json` jusqu'à ce qu'on retire l'étoile. La case à cocher **Favoris seulement** (à droite des onglets ; clic, touche **F** ou touche Carte) ne garde dans la liste de l'onglet ouvert que ses favoris, y compris ceux des sessions précédentes ; elle reste cochée d'un onglet à l'autre. **F1 = infos seulement** (affichées en haut à droite). Les réglages sont enregistrés dans `dq4_pc\reglages.json`, les états dans `dq4_pc\sauvegardes\etats\` ; ils ne contiennent aucun fichier du jeu. Options de la ligne de commande : `--slot N` (1 à 5 : charge ce journal sans logos ni titre ; 0, par défaut : logos, titre et menu de départ), `--sans-logos`, `--reglages fichier.json`, `--sans-son`, `--hd` (0, 1 ou 4), `--msaa`, `--plein-ecran 0|1` (2 vaut 1), `--correction-bords 0-100` (débogage ; la correction est toujours active), `--carte-zoom` (zoom de 0,5 à 2 ; 1 = distance de la caméra à 100 %), `--volume-musique`, `--volume-bruitages` (elles passent avant les réglages du menu).
